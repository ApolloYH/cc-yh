# AutoDream 归档说明

AutoDream 是上游 Claude Code 记忆系统中的后台整理思路。本项目当前不把 AutoDream 作为主路径使用。

claude-yh 当前记忆策略是：

- 原有 memory 写入机制保留为主系统。
- L1-L4 是增强层，而不是一套平行记忆。
- 普通聊天期间不每轮完整抽取。
- 会话关闭、切换会话、应用退出或长时间空闲后，基于整个会话增量整理一次。
- L1 只保存压缩摘要和检索入口。
- L2 保存长期事实、偏好、角色定位和稳定规则。
- L3 保存可复用 SOP，claude-yh 专属 Skills 走独立 discovery。
- L4 保存原始会话摘要和溯源信息。

如果需要研究上游 AutoDream 思路，可以把它作为背景资料参考，但不要把它当成当前 claude-yh 的运行机制。
